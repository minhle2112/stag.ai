Bản 1 · Xưởng

IDE tối, dày, ưu tiên bàn phím. Lưới ô CLI là trung tâm; mọi thứ khác gọi bằng Ctrl K hoặc thanh trái. Teal = điểm nhấn · xanh lá = đang chạy · hổ phách = chờ bạn · đỏ = nguy hiểm. Rê chuột lên biểu tượng để xem tên.

MÀN HÌNH
  1. Agent — lưới ô; kéo tiêu đề để đổi chỗ; nút ▾ cạnh “+ Agent” để thêm terminal / widget
  2. Trình duyệt — bảng bên phải, nút quả cầu trên thanh tiêu đề (Ctrl+Shift+B); kéo mép trái để đổi độ rộng
  3. Kanban · Artifacts · Vault · Nhật ký & bộ nhớ · Cài đặt — thanh trái hoặc Ctrl+1…5; plugin thêm mục riêng dưới vạch ngăn (Ctrl+6)
  4. Workspace — tất cả ở thanh bên; bấm tên để chuyển, mũi tên để mở / thu
TIỆN ÍCH MỚI ĐỀ XUẤT
  1. Thay đổi theo agent — trong Artifacts, nhóm / lọc theo agent; hoàn tác riêng một agent hoặc từng tệp, không cần git worktree (biểu tượng tệp ± trên tiêu đề ô)
  2. Chế độ tập trung — một ô toàn màn, ô khác thành dải mini (Ctrl+Shift+F)
  3. Phát lệnh — một tin cho nhiều agent, chờ rảnh mới dán
  4. Dòng thời gian phiên — kéo thanh trượt xem lại ai làm gì lúc nào
  5. Git theo agent — thay đổi chưa commit nhóm theo agent, commit từng phần (nhánh ở thanh trạng thái)
